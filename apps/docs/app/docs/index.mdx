# Config Manager Service

Welcome to the **Config Manager Service** documentation.

This service provides:

- A centralised configuration platform
- Multi-environment config (dev, staging, prod)
- REST API with Swagger docs
- TypeScript SDK for programmatic access
- Audit logging, versioning, and rollback
- Dashboard UI for managing entities and configs

---

## What is this service?

It is a configuration management platform built to help teams:

- Store service configs securely  
- Manage multiple environments  
- Track changes with full audit logs  
- Integrate with backend services via SDK  
- Provide centralized config governance
